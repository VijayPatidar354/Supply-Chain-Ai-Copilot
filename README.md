📦 Supply Chain AI Copilot

An AI-powered analytics dashboard that helps analyze supply chain order data and answer operational questions using natural language.

The system combines data analytics, interactive visualizations, and a Large Language Model (LLM) to help supply chain managers quickly understand logistics performance.

Features
1. Interactive Dashboard
  Visualize key logistics metrics including:
  Average delay by warehouse
  Average delay by product
  Delay distribution
  Warehouse performance comparison

2. Supply Chain Health Score
  A gauge indicator that summarizes the overall logistics performance.
  The score is calculated based on the average shipping delay.
  Score Range	Status
    90–100	Excellent
    70–90	Good
    40–70	Needs Improvement
    0–40	Critical

3. AI Copilot
  Ask questions about the dataset using natural language.
  Examples:
    Which warehouse has the highest delay?
    Which product ships fastest?
    What is the average delay per warehouse?
    Which product has the highest delay?
  The AI answers using dataset insights generated by the system.

4. Data Filtering
  Users can filter the dataset by:
    Warehouse
    Product
  This allows users to explore specific segments of the supply chain.

5. Dataset Viewer
 View the filtered dataset directly inside the dashboard.

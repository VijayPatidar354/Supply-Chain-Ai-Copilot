📦 Supply Chain AI Copilot

The Supply Chain AI Copilot system is designed as a data-driven analytics dashboard combined with an AI assistant that helps users analyze logistics performance and answer supply chain–related questions. The system processes uploaded order datasets, performs analytics using Python, visualizes operational metrics, and integrates a Large Language Model (LLM) for natural language interaction.

Features
1. Interactive Dashboard
  Visualize key logistics metrics including:
  Average delay by warehouse
  Average delay by product
  Delay distribution
  Warehouse performance comparison

2. Supply Chain Health Score
  A gauge indicator that summarizes the overall logistics performance.
  The score is calculated based on the average shipping delay.
  Score Range	Status
    90–100	Excellent
    70–90	Good
    40–70	Needs Improvement
    0–40	Critical

3. AI Copilot
  Ask questions about the dataset using natural language.
  Examples:
    Which warehouse has the highest delay?
    Which product ships fastest?
    What is the average delay per warehouse?
    Which product has the highest delay?
  The AI answers using dataset insights generated by the system.

4. Data Filtering
  Users can filter the dataset by:
    Warehouse
    Product
  This allows users to explore specific segments of the supply chain.

5. Dataset Viewer
 View the filtered dataset directly inside the dashboard.

6. System Architecture
CSV Dataset
     │
     ▼
Data Processing (Pandas)
     │
     ▼
Analytics & Metrics
     │
     ├── Dashboard Visualizations (Plotly)
     │
     └── AI Copilot
            │
            ▼
        Groq LLM API
            │
            ▼
      Natural Language Answers

7. Work Flow 

User uploads dataset
        ↓
Data processing module calculates metrics
        ↓
Dashboard visualizes supply chain performance
        ↓
Summary insights generated
        ↓
User asks question to AI Copilot
        ↓
Prompt sent to LLM via Groq API
        ↓
AI generates response
        ↓
Answer displayed in dashboard

8. Tech Stack Used

Python
Streamlit – dashboard framework
Pandas – data processing
Plotly – interactive charts
Groq API – Large Language Model inference
dotenv – environment variable management

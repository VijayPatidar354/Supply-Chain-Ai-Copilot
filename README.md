# Supply Chain AI Copilot

An AI-powered analytics dashboard that analyzes supply chain order data and answers operational questions.
It is designed to give Answers to the Question related to the supply chain data like 
1.Which warehouse has the highest delay?
2.Which product ships fastest?
3.What is the average delay per warehouse?,etc.
## Features

- Interactive dashboard
- Delay analytics
- Warehouse performance comparison
- AI question answering using LLM
- CSV dataset upload

## Tech Stack

- Python
- Streamlit
- Pandas
- Groq API

## Run the Project

```bash
pip install -r requirements.txt
streamlit run app.py
